# 排序程序

一个 C++ 写的小型排序演示程序，支持多种排序算法选择，安装时可选中文 / English / 日本語。

## 功能

- 计数排序
- 插入排序
- 输入 `N` 退出程序

## 安装

- 仅支持 **Windows**
- 直接下载 releases\......exe，双击安装即可使用

## 项目结构

```
.
├── src/              # 主程序源码
├── include/          # 头文件（排序函数）
├── assets/           # 资源文件（图标）
├── releases/         # 安装包（成品）
├── .vscode/          # VS Code 配置
└── .gitignore        # Git 忽略规则
```
